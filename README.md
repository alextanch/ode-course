# Практические занятия по дифференциальным уравнениям

Практика у студентов 2 курса бакалавриата технического университета ИТМО, базовый курс дифференциальных уравнений.

**Формат:** 8 занятий по 1 ч 30 мин: 6 практик, контрольная и переписывание.
